# Vector Toolset Branding

## Name

Vector Toolset. In the interface the mark is VECTOR, with Toolset as the descriptor beside or beneath it.

## Feel

Intuitive and stress free, built the way an IT specialist would want it. Calm, dark, high signal, low noise. It should feel confident and professional, never gimmicky, because it touches other people's machines and data.

## Design principles

- Calm and dark by default. Techs work long sessions, often in dim rooms. Low glare, high contrast only where it matters.
- High signal, low noise. Every color and label means something. Status colors map to real states, not decoration.
- Fast and out of the way. Sane defaults so a junior tech is never lost, but no wizards that slow an expert down.
- Consistent and learnable. Same layout, same icon language, same shortcuts everywhere, so muscle memory builds fast.

## Palette

Orange accent on dark gray and black. Orange is reserved for brand and interactive elements. Warnings use a separate yellow so they never blend into the accent.

## Typography

- A clean sans for the interface.
- A monospace for data, paths, readouts, and anything tabular.
- Readable at a glance, generous spacing.

## Voice and copy

Plain, competent, brief. Buttons say exactly what they do. Errors say what happened and what to do next. No filler, no jokes, no apologies.

## Where branding appears

- The GRUB boot menu splash and theme.
- The launcher: header, colors, icons, the whole feel.
- Generated diagnostic reports: branded header and shop name.
- The repo README and docs.

## Writing rules for this project

All written output, in the repo and elsewhere, stays concise, well organized, easy to read, and human sounding. No AI references. No emoji, em dashes, or special symbols. Plain keyboard characters only, as if typed by a person.
